# mnanak na qalang｜互動有聲繪本

使用老師提供的 20 頁圖片、20 段朗讀、20 段背景音樂與主題歌曲製作。

## 功能
首頁、20 頁閱讀、上一頁／下一頁、快速跳頁、閱讀進度、縮圖目錄、手機滑動、全螢幕與放大、朗讀／暫停／重播、朗讀倍速、背景音樂與音量調整、一鍵靜音、朗讀時音樂降低、自動翻頁／連續朗讀、每頁看圖導讀、可隱藏文字、每頁筆記自動儲存、閱讀位置書籤、圖片互動探索、五題小測驗、除錯資訊。

注意：看圖導讀是根據圖片撰寫的觀察提示，不是族語逐字稿或翻譯；每頁心得只儲存在使用者目前瀏覽器中。

## GitHub Pages
把此資料夾**裡面所有檔案與 graphics、music、speech 資料夾**上傳到儲存庫根目錄（不要只上傳 ZIP）。Settings → Pages → Deploy from a branch → main / (root) → Save。網址通常是 https://wengching0.github.io/drawingbook/ 。

瀏覽器通常限制自動播放：進入閱讀器後，按一次播放或朗讀才能啟用聲音。GitHub Pages 發布後再以手機與電腦測試。
